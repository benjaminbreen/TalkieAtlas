# Neuron expansion, October 27, 2026

The raw run contains 1,000 fresh neurons, both signs at two strengths, plus pair trials and reruns. The main library adds the 18 solo replies and 27 pair replies listed in the review files, each with a custom robot and subjective Codex weirdness/coherence scores. Additional raw trials are retained for later inspection; selection is not an eligibility boundary. Interesting repetition is acceptable. No separate presentation page is added in this release.

The user prefers plain Markdown for future research reports and direct additions to the existing library when requested. See the repository AGENTS.md.
